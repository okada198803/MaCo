# MaCo 錬成アプリ（maco_train.html）

**MaCo 錬成アプリ**は、MaCo（Marksmanship Coach）のうち、日々のドライファイア錬成で使うための Web アプリです。撃発を自動で検知し、その場で予測点数・3段階の評価・低下要因と対処を表示し、全ショットを端末内に記録します。

開発用アプリ（`index.html`）が「参照デバイスのスコアと生データを突き合わせる教師データ収集」用であるのに対し、錬成アプリは**参照デバイスなしで、検証済みのアルゴリズムを使って錬成する**ことを目的としています。外部ライブラリに依存せず、オフライン（射場）でも動作します。

> 対象は右利き・拳銃です。方向と低下要因の対応、説明・対処要領はこの前提で作っています。

---

## 構成

| コンポーネント | 役割 |
|---|---|
| **M5StickS3 ファームウェア**（`m5stick_firmware/`） | IMU の角速度・加速度を 100Hz で BLE 送信するのみ（開発用アプリと共通） |
| **錬成アプリ**（`webapp/maco_train.html`） | 撃発の自動検知・採点・低下要因の提示・記録・振り返り・書き出し |
| **開発用アプリ**（`webapp/index.html`） | 教師データ収集・アルゴリズム検証用。採点・方向判定・銃種のコードは錬成アプリと同一 |
| **軸確認ツール**（`webapp/axis_check.html`） | 取り付け位置を変えたときの軸対応の確認 |

1ファイルの HTML で、画面は「錬成」「振り返り」「設定」の3タブです。錬成タブは、点数・低下要因・軌跡が1画面（iPhone 13 程度）にスクロールなしで収まり、軌跡は画面の高さに合わせて伸縮します。直近10発・手動追加・新規セッションは下にスクロールして表示します。

---

## 処理の流れ

```
BLE受信(100Hz) → 撃発の自動検知 → 前後の静止確認 → 採点(撃発+250ms) → 結果表示・記録 → スライド操作 → 再待機
```

### 1. 撃発の自動検知

加速度の大きさの差分を常時監視し、次の条件をすべて満たしたものを撃発とします。

| 段階 | 条件（既定値） |
|---|---|
| 候補 | 加速度差分が 0.08 G/サンプル以上。最初の超過から 150ms 以内の最大ピークを撃発時刻（T0）とする |
| ジャイロゲート | ピーク前100ms〜後50msの合成角速度が 150 dps 未満 |
| 衝撃幅 | ピーク±150ms で 0.3×ピーク超のサンプルが 8 個以下（撃発の衝撃は短い） |
| 静止ゲート | 撃発前（−1000〜−150ms）と撃発後（+100〜+500ms）の最大角速度が **60 dps 以上なら棄却**、**20 dps 以上なら「要確認」**として記録 |

- 本物の撃発は前後ともほぼ静止しています（既存データで撃発前の最大 50 dps、撃発後の最大 37 dps）。持ち替えやスライド操作中の衝撃は前後に大きな動きがあるため棄却します。
- 「要確認」のショットは記録しますが、集計からは除きます。破線の枠と縞模様のバーで区別して表示します。

#### 照準の保持の確認（2026-10-23 追加）

撃発前3秒（-3000〜-150ms）の合成角速度の中央値で、照準を保持していたかを確認する。

- 4 dps 以上：構え直し・持ち替え中とみなし、撃発としない。
  - ただし直前1秒（-1000〜-150ms）の中央値が 2.6 dps 未満なら、据銃直後の撃発とみなし「要確認」で記録する。
- 0.5 dps 未満：手で保持していない（台に置いた状態等）とみなし、撃発としない。
- 本物の撃発の中央値は 0.86〜3.0 dps（既存の VP9・Glock17・GBB 計688発と 2026-10-23 の VP9 錬成）。
- 誤検知は 4.5〜57 dps（構え直し・持ち替え）と 0.2 dps（銃を横にして置いた状態）。
- 練成モードの制限時間内は、ブザー後すぐに据銃するため使わない。

### 2. 再待機（スライド操作の判定）

撃発後は次の状態を順に進み、次弾の検知に戻ります。

`待機中 → 判定中 → 撃発検知 → スライド操作待ち → スライド操作中 → 待機中`

- スライド操作: 合成角速度 100 dps 以上、または加速度差分 0.3 G 以上
- 静止: 角速度 30 dps 未満・加速度差分 0.1 G 未満が 600ms 続くと再待機
- スライド操作が検出されない場合は 8 秒で自動的に再待機します。画面上部（BLE接続の左）の「次弾準備」ボタンでいつでも再待機できます。

### 3. 採点（予測点数）

撃発前後の角速度と軌跡から、参照デバイスの点数（0〜100）を予測します。

- 特徴量（45個）:
  - 撃発 −400〜+100ms を 25ms ごとに区切った、ロール角速度の絶対値と上下・左右の合成角速度の平均
  - 撃発前後100msの軌跡の変位
  - 撃発前400msの軌跡の広がり
  - 撃発瞬間（−150〜+50ms）の最大角速度
- 学習: 6セッション 407 発、外れ値に強い Huber 損失の線形回帰
- 精度（学習に使っていない日のデータで評価）: 平均誤差 5.9 点、±10点以内 85%

予測点数から3段階の評価を表示します。

| 帯 | 予測点数（既定） | 目安 |
|---|---|---|
| 高 | 88 以上 | 実測 90 点以上 |
| 中 | 72〜88 | |
| 低 | 72 未満 | 実測 70 点未満 |

**読み方の注意**
- 予測点数は ±10 点程度の幅で読んでください。
- 低得点は高めに出る傾向があります（実測 50 点未満で平均 +6〜7 点）。
- 撃発時刻が 10ms ずれると約 1 点、20ms で 3〜5 点悪化します。

### 4. 低下要因（7方向判定）と程度

撃発前後200msの銃口の動き（始点→終点）の方向から、低下要因の候補を判定します。

| 方向 | 低下要因 |
|---|---|
| 右 | 指掛け過剰・サミング |
| 右上 | 反動予期 |
| 上 | 銃口上がり・押し込み |
| 左 | 指のかかりが浅い |
| 左下 | トリガースラップ・握り込みすぎ |
| 下 | 突き出し・銃口下がり |
| 右下 | 引き金を引きながら握り込み |
| 左上 | 未定義（押し込み・フォロースルー不足の想定領域だが、データで裏付けが取れていない） |

動きが 0.3° 未満のときは方向を判定しません。表示は帯によって次のとおりです。
- 「高」帯: 問題なし
- 「中」「低」帯: 動きが小さく、方向の特徴なし

方向が出た場合は**程度**を併記します（例: `銃口上がり・押し込みの可能性｜軽度（0.42°）`）。

| 程度 | 動き量 | 読み方 |
|---|---|---|
| 軽度 | 0.3〜0.6° | 傾向の段階。高得点のショットでも見られる |
| 中度 | 0.6〜1.0° | 点数に影響している可能性が高い |
| 重度 | 1.0° 以上 | 最優先で矯正する |

**精度と注意**
- 参照デバイスの低下原因との一致率は約 77% です。表示は候補であり、断定ではありません。
- 左下の2要因（トリガースラップと握り込みすぎ）は、方向だけでは区別できません。
- 反動予期は右や「なし」にも出ることがあります。
- 「高」帯で出る方向は、参照デバイスの原因と一致しにくい（約 2 割）ため、軽い傾向として読んでください。

### 5. 説明と対処要領

低下要因ごとに、状態の説明、対処の要点、矯正ドリルを用意しています。

| 表示場所 | 内容 |
|---|---|
| 錬成画面の結果欄 | 「対処：〜」の1行 |
| ショット詳細 | 説明・程度の読み方・対処（2〜3項目）・矯正ドリル（タップで展開） |
| 振り返りの要因集計 | 多かった要因の順に説明と対処（最多のみ展開） |

内容は一般的な射撃指導に基づくもので、コード内の `CAUSE_GUIDE` で編集できます。

### 6. 銃種

採点モデルは VP9 のデータで学習しています。銃種は「VP9」「Glock17」「Glock17 ガスブローバック」から選びます。Glock17 では同じ点数でも撃発前の動きが大きく出るため、VP9 モデルのままでは平均約 7 点低く予測されます（2セッションとも同じ傾向）。「設定」の「銃種」で Glock17 を選ぶと、次の補正を行います。

| 項目 | VP9 | Glock17 |
|---|---|---|
| 採点モデル | VP9 で学習したモデル | VP9 と Glock（2セッション181発）を合わせ、銃種を考慮して学習したモデル |
| 予測精度（Glock） | 平均誤差 9.6 点・±10点以内 67% | 平均誤差 5.6 点・±10点以内 88% |
| 程度の区分 | 軽度 0.3〜0.6°／中度〜1.0°／重度 1.0°以上 | 境界を 1.3 倍（軽度 0.3〜0.78°／中度〜1.3°／重度 1.3°以上） |

- 精度は、Glock の1セッションを学習から除き、そのセッションで評価した値です。
- 銃種はショットごとに記録され、振り返り・書き出しでは記録時の銃種で再計算します。
- 開発用アプリ（index.html）にも同じ銃種設定があります（キャリブレーション設定パネル）。

#### ガスブローバック（Glock17 GBB）

ガスガンは撃発直後にスライドが後退し、銃口が大きく跳ね上がります。ドライファイア用の判定のままでは撃発がほぼ検知されず、点数も0点付近になるため、専用の判定に切り替えます。

| 項目 | ドライファイア（VP9・Glock17） | ガスブローバック |
|---|---|---|
| 撃発時刻 | 加速度の衝撃のピーク | 反動で角速度が跳ね上がる直前のサンプル |
| 撃発の検知 | ジャイロゲート・衝撃幅・撃発前後の静止 | 反動の大きさ（100 dps 以上）と撃発前（−1000〜−150ms）の静止 |
| 次弾の待機 | スライド操作→静止で再待機 | 撃発の約0.6秒後から静止を確認して再待機 |
| 採点 | 撃発 −400〜+100ms | 撃発前のみ（−400〜0ms）＋96点未満の補正 |
| 方向判定 | 撃発 ±200ms・0.3° 以上 | 撃発前のみ（−200〜0ms）・0.08° 以上 |
| 程度の区分 | VP9 0.6/1.0°、Glock17 0.78/1.3° | 軽度 0.08〜0.40°／中度〜0.77°／重度 0.77° 以上 |

- 採点の補正: ガスブローバックでは、撃発前の動きが同じでも Mantis の点数がドライより低く出ます。96点未満の予測は、96点からの差を1.45倍に広げて補正します（96点以上はそのまま）。
- 検証（2セッション100発）: 全発を検知。予測の平均誤差は、高得点帯（86〜99点）で約2〜3点、点数の幅が広いセッション（1.6〜98.5点）で約7.7点（補正なしでは10.6点）。補正は2セッション目のデータで決めたため、別の日のデータで再確認します。
- 撃発前の動きはドライファイアより小さく出るため、方向を判定する最小の動きを 0.08° にしています。
- 1秒以内の連射には対応していません。
- 開発用アプリでガスブローバックを記録するときは、銃種を「Glock17 ガスブローバック」にしてください。反動の無い位置を撃発として選ぶと警告が出ます。
- Mantis の「ショット検出遅延」は2回目の検出を無視する設定です。MaCo では撃発後に静止を確認してから次弾待機に戻るため、同じ設定は不要です。

### 7. 練成モード（ブザー・時間計測）

錬成画面の上部で次の3つから選ぶ。2・3は「開始」を押すと、3秒後に第1ブザーが鳴る。

1. **自由練成**: 時間制限なし。撃発ごとに採点する（従来どおり）。
2. **1コ的**
3. **3コ的**
4. **至近射撃（姿勢変換）**：MaLIの射撃要領（連続射撃、下記）
5. **制圧致命射撃（昼間）**：同上
6. **制圧致命射撃（夜間）**：同上
7. 以降 **カスタム練成**（設定で追加。下記）

| モード | 1回の流れ | 回数 |
|---|---|---|
| 1コ的 | 開始ブザー → 3秒以内に1発 → 終了ブザー → 5秒休止（スライド操作） | 4回 |
| 3コ的 | 開始ブザー → 2秒以内に1発 → 終了ブザー → 3秒休止（スライド操作）。回ごとに的1→的2→的3 | 3回 |

- **ブザー**: 開始は高音1回、終了は低音2回。iPhone のマナーモード中は音が出ません。
- **バー表示**: 開始前は灰、射撃中は緑（経過秒）、休止中は青（次の回までの秒）。
- **記録**: 各発に「何回目か・的・ブザーから撃発までの時間・時間内／時間外」を付ける。
  - 終了ブザー後 1 秒以内の撃発は「時間外」として記録する。
  - それ以降と開始前の自動検知は、休止中のスライド操作等とみなし記録しない（「検知の診断」に残る）。
  - 同じ回に2発検知した場合、2発目は「同じ回の2発目」とし、集計に入れない。
- **撃発前の静止確認**: 制限時間内（時間外の猶予を含む）は、撃発前 -500〜-150ms で確認する。動きが大きくても棄却せず「要確認」とする。ブザー直後の据銃や的の移動で撃発が取りこぼされないようにするため（暫定。練成データで要検証）。
- **待機への復帰**: 各回の開始ブザーの時点でスライド待ち等のままなら、自動で待機に戻す。
- **終了時**: 結果欄に、時間内の発数・平均の反応時間・最大の傾き・各回の結果を表示する。振り返りタブにも「練成モードの結果」として残る。点数の平均は、時間内かつ「要確認」でない発で求める。
- **反応時間の精度**: M5 の時刻と画面の時刻の対応は「受信時刻 − M5時刻」の直近約5秒の最小値で取る。BLE の遅れのばらつきと音の出力遅れで、数十ms程度の誤差を見込む（未検証）。
- **的の移動**: 3コ的の的番号は表示のみ。正しい的へ振ったかは判定しない。

#### 銃種による切り替え（ドライ／ガスブローバック）

選択肢は共通で、「設定」の銃種に合わせて中身を自動で切り替える。名称に「・ドライ」「・GBB」が付き、振り返り・分析では別の練成として扱う。

| 練成 | ドライ | ガスブローバック |
|---|---|---|
| 1コ的・3コ的（反復） | 休止 5秒・3秒（スライド操作） | 休止を短縮（既定 2秒・2秒、設定で変更） |
| カスタム（反復） | スライド操作時間 | 「休止（ガスブローバック時）」の値 |
| MaLIの要領・カスタム（連続） | 目標の射撃間隔・合計時間に、1発あたりのスライド操作時間（既定 1.5秒）を加算 | 実弾の目標値のまま |

例：至近射撃のドライの目標は 間隔 2.0＋1.5＝3.5秒、合計 30＋1.5×8＝42秒（弾倉交換をまたぐ間隔は除く）。

#### 連続射撃（MaLIの射撃要領）

開始ブザー1回のあと、規定の発数を続けて撃つ。MaLI（射撃術技量評価ツール）の射撃要領と同じ構成・評価にしている。

| 要領 | 発数・的 | 弾倉交換 | 目標（MaLIの評価B基準、秒） |
|---|---|---|---|
| 至近射撃（姿勢変換） | 10発（的1:4・的2:3・的3:3） | 7発目の後 | 初弾1.0・間隔2.0・合計30・弾倉交換4.0 |
| 制圧致命射撃（昼間） | 5発（的1） | なし | 初弾1.0・間隔0.8・合計5 |
| 制圧致命射撃（夜間） | 5発（的1） | なし | 初弾1.5・間隔1.5・合計8 |

- **弾倉交換・弾づまり対処ボタン**: 練成の実施中だけ画面下に出る。押している間の時間を記録する（0.2秒未満は無視、記録はタップで削除）。記録中の検知は撃発としない（交換動作の誤検知を防ぐ）。
- **指標**（MaLIと同じ定義）: 初弾＝ブザーから1発目、合計＝ブザーから最終弾、間隔＝隣り合う発の差の平均（弾倉交換をまたぐ間隔は除き、ボタンの記録時間を差し引く）、弾倉交換＝ボタンの記録時間（実測）。ボタンを使わない場合は（交換後の初弾−交換前の最終弾）−目標初弾（推定）。
- **評価**: 実測÷目標で A（0.85以下）・B（1.15以下）・C（1.40以下）・D。目標はMaLIの実弾の値。**ドライでは1発ごとのスライド操作が間隔・合計に含まれるため参考**。ガスブローバックなら連射のまま評価できる。
- **終了**: 規定の発数に達して1.5秒後に自動で終了。「終了」ボタンでいつでも終了できる（制限時間なしは3分で打ち切り）。
- **ガスブローバック**: 反動が収まる0.25秒後に次の発を待つ（通常は静止確認のため約1.2秒）。直前の発の反動は撃発前の動きに含めない。
- **連射の点数**: 前の発から0.6秒未満の発は、採点に使う撃発前0.4秒に前の発の反動が入るため「参考」とし、平均から除く。
- カスタム練成でも形式「連続」を選ぶと、発数・的の割当（例 4,3,3）・弾倉交換（何発目の後）・制限時間・目標値を設定できる。

#### カスタム練成

「設定」タブの「カスタム練成」で追加・編集・削除する。複数登録でき、錬成画面上部の選択肢に「7」以降として表示される。1〜6は固定。形式は「反復（1回ごとにブザー・1発）」と「連続（ブザー1回で続けて撃つ）」から選ぶ。下の表は反復の項目。

| 項目 | 範囲 | 追加時の値 |
|---|---|---|
| 名称 | 16文字まで | カスタムN |
| 射撃時間 | 0.5〜60秒（0.1刻み） | 3秒 |
| スライド操作時間（休止） | 0〜60秒（0.5刻み） | 5秒 |
| 試行回数 | 1〜50回 | 5回 |
| 的数 | 1〜10個（回ごとに的1→2→…と表示） | 1個 |
| 開始までの秒数 | 1〜30秒 | 3秒 |

- 端末に保存し、「設定を初期値に戻す」では消えない。
- 記録した発には実施時の設定を保存するため、あとで編集・削除しても振り返りは実施時の名称・内容で表示する。
- 時間外の猶予（終了ブザー後1秒）は全モード共通の設定を使う。

#### 練成の分析（振り返り）

振り返りタブの「練成の分析」で、全セッションの練成モードの発をまとめて分析する。練成者・練成内容で絞り込む。

- **推移**: 練成1回ごとの平均点・時間内率・平均反応時間（1つの図に1つの指標）。点をタップすると日時と値を表示。
- **何発目ごと／的ごと**: 発数・時間内率・平均反応時間・平均点。的ごとは的数2以上のとき。
- **反応時間と点数**: 散布図（●時間内・○時間外、点線は射撃時間）。時間内の発が6発以上で、速い1/3と遅い1/3の平均点と、反応0.5秒あたりの点数の変化（最小二乗、目安）を表示。
- 点数は時間内かつ「要確認」でない発、反応時間は時間内の発。時間内率は時間内の発数÷実施した回数（未射撃を含む）。同じ回の2発目は除く。

#### 練成者

「設定」タブの「練成者」に入力すると、以降のショットに練成者を記録する。画面上部の銃種表示に併記し、振り返りのセッション一覧・CSV（末尾の「練成者」列）にも出す。

#### 音声（Bluetoothイヤホン）

iPhoneの音はそのまま接続中のBluetoothイヤホンから出る。画面を見ずに練成できるよう、次を追加した（「設定」→「音声（Bluetoothイヤホン）」）。

- **結果の読み上げ**（既定：自由練成以外）: 撃発ごとに「92点」「時間外、85点」のように読み上げ、練成の終了時に「時間内、4発中3発、平均88点、反応1.4秒」とまとめて読む。連続射撃は射撃の妨げになるため終了時のみ。「常に」にすると自由練成でも読む。
- **低下要因を含める**（既定：オフ）: 中・低のときに「75点、トリガースラップ」と読む。長くなり次のブザーと重なることがある。
- **音の出力遅れ**（既定：0ms）: イヤホンは音が耳に届くまでに遅れ（AirPods等で約150〜250ms）があるため、設定値を反応時間から差し引く。自動では測れないため、機種の公表値や体感で設定する。
- **接続の維持**: イヤホンは無音が続くと音の頭が欠けることがあるため、練成中はごく小さい音を流し続ける。
- 「ブザーをテスト」「読み上げをテスト」で、音量と接続を事前に確認できる。マナーモード中は鳴らない。

### 8. 傾き（カント）

- 撃発直前（-300〜-50ms）の加速度（重力方向）から、銃身軸まわりの傾きを求める。右へ傾けると正（「右」と表示）。
- 結果欄・ショット詳細・振り返りに表示し、CSV にも出力する。注意の値（既定 3°、暫定）以上は ⚠ を付ける。
- **0点**: 「静止バイアスと傾きの0点を記録」（銃に装着する前、置いた状態）で、置いた向きを0°にする。
  - 画面を下向き・上向きのどちらにしても、正立で0°付近になる（上下逆の取り付けは銃身軸まわりの180°回転として扱う）。
  - 装着後の取り付けの傾きまで除く場合は、「傾きの0点を記録し直す」を押し、3秒後から1秒間、照準を正立させて構えて静止する。
- 錬成画面の上部（練成を実施していない間）に、現在の傾きを表示する。初回は銃を右へ傾けて「右」と出ることを確認する（軸の向きは既存の軸対応から導いた値で、実機では未確認）。
- 既存データ（VP9・Glock17）の撃発時の傾きは、取り付けの傾きを含めて左 1〜3° 程度、発ごとのばらつきは約 0.5° だった。

## 使い方

1. **装着**: M5StickS3 を銃口下のレールに固定する（画面下向き・端子が射手側）。
2. **アプリを開く**: `webapp/maco_train.html` を Web Bluetooth 対応ブラウザ（iPhone は Bluefy）で開く。端末の画面自動ロックは無効にしておく。
3. **BLE 接続**: 「BLE接続」を押し、`MaCo-S3` を選択する。
4. **銃種の確認**: 「設定」タブの「銃種」が使用する拳銃になっているか確認する。
5. **静止バイアスの記録**: 「設定」タブで、**銃に装着する前に**置いた状態で「静止バイアスを記録」を押す。
   - 記録は端末に保存され、次回以降も使われます。
   - 動いている状態で押すと、記録せずにやり直しを求めます（持った状態で記録すると軌跡が大きく流れるため）。
   - 12時間以上経つと再記録を促すバナーが出ます。
6. **錬成**: 状態表示が「待機中」になったらドライファイアする。練成モードを使う場合は、上部で「2 1コ的」「3 3コ的」を選んで「開始」を押す（上の7を参照）。撃発を自動で検知し、予測点数・帯・低下要因・対処が表示される。
7. **次弾**: スライドを操作して静止すると「待機中」に戻る。戻らないときは画面上部の「次弾準備」を押す。
8. **取りこぼし**: 検知されなかった撃発は「撃発を手動追加」で、波形から撃発位置を指定して追加する。
9. **振り返り**: 「振り返り」タブで次の内容を確認する。
   - セッションの集計(発数・平均・ばらつき・帯の内訳)
   - 点数の推移
   - 要因の集計と説明
   - ショット一覧
10. **ショットの修正**: 一覧のショットをタップすると、詳細の確認と次の操作ができる。
   - 撃発位置の修正
   - 誤検知の削除
   - 参照スコア・低下原因の入力
11. **書き出し**: 「CSV 共有・保存」を押すと、準備後に書き出しシートが開く。
    - 「共有・保存」→「ファイルに保存」で端末に保存する。
    - うまくいかない場合は「コピー」してメモ等に貼り付ける。
12. **新規セッション**: 「新規セッション」で区切る。前のセッションは振り返りに残る。

## 記録と書き出し

- 端末内の IndexedDB（`maco-train`）に、セッション・ショット・生波形（撃発前5秒〜後1秒）を自動保存します。ブラウザのデータを消去すると記録も消えます。
- **ショット CSV**: 開発用アプリと同じ列構成に、次の列を加えたものです。
  - 予測帯
  - 判定低下要因（程度を含む）
  - 検知品質（通常／要確認）
  - 撃発前最大dps・撃発後最大dps
  - 銃種
  - 傾きdeg（右が正）
  - 練成シナリオ・回・的・反応時間ms・時間内（練成モードの発のみ）

  開発用アプリ側の解析にそのまま使えます。
- **連続生データ**: 「設定」で「連続生データを保存」をオンにすると、受信した全サンプルを保存します。検知ルールの検証用で、生波形が無いショットの CSV 再構築にも使います。
- iOS では共有の操作がタップ直後でないと拒否されることがあるため、書き出しを「準備」と「共有／コピー／ダウンロード」の2段階に分けています。

## 既知の制約・今後の課題

- **実機での再検証が未実施**: 静止ゲート、要確認の表示、書き出しの2段階化、新しい採点モデル、程度・説明の表示。
- **要確認のしきい値**: 20 dps を 15 dps に下げても誤検知と実射の判別は改善しなかったため、20 dps を維持しています（最終判断は保留）。
- **低得点の過大予測**: 実測 50 点未満では予測が高めに出ます。低得点帯のデータ追加が必要です。
- **左上方向**: 押し込み・フォロースルー不足の判定は裏付けが無く、未定義です。
- **取り付け**: 取り付け位置・向きを変えた場合は `axis_check.html` で軸の対応を確認してください。採点モデルは現在の取り付けで学習しています。
- **銃種**: 対応は VP9、Glock17、Glock17 ガスブローバックのみです。他の拳銃では、参照スコア付きのデータで精度を確認してから使ってください。
- **サンプリングレート**: 100Hz。引き上げは検討中です。
- **練成モード**: 実機未検証。ブザー直後の速い撃発での採点精度（学習データは時間制限の無い撃発）、撃発前の静止確認の緩和（-500ms・要確認扱い）、反応時間の誤差、傾きの符号を、連続生データを保存した練成で確認する必要があります。
